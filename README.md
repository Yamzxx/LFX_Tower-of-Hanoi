# Tower of Hanoi – LFX Coding Challenge

This project demonstrates the classic Tower of Hanoi problem using HTML, CSS, and JavaScript.

## Features
- Recursive solution implementation
- Visual disk movement
- Simple interactive UI
- Demonstrates recursion and iteration concepts

## Recursion
The recursive function repeatedly moves smaller disk sets between rods until the puzzle is solved.

## Technologies Used
- HTML
- CSS
- JavaScript
